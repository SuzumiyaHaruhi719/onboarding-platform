# 编辑器 UX 启发式评估(Claude + Codex 联合)· 2026-06-08

方法:全屏截图(gstack browse)+ Codex CLI 只读评审 + Nielsen 10 启发式 + 对标 Notion/Coda 块编辑器。

## 问题清单(按严重度)

### CRITICAL
1. **空章节像坏掉了** — 唯一的"添加首块"入口用 `.insert-line`,而它 `opacity:0`(只在 hover 显示)→ 空章节看不到任何添加入口。**修**:真正的空状态卡片 + 常驻主按钮「添加内容块」+ 次按钮「AI 转译文件」。
2. **没有自动保存 / 保存状态不清** — 标题、最短阅读要手动点「保存」。**修**:标题/时长/块编辑自动保存,带状态「保存中…/已保存」。
3. **AI 流程暴露实现细节** — token/日志直接铺在主界面。**修**:清晰三步(上传→预览→选位置),日志收进「查看详情」。
4. **悬停工具条遮挡正文**(截图可见)— `.eb-ctrl` 浮在块右上,盖住文字。**修**:控件移到**左侧栏槽**(gutter),不与正文重叠。

### HIGH
5. **插入控件 hover 才出现 → 不可发现**。**修**:Notion 式**左栏常驻「+」**,每块旁可加。
6. **加块是"表单优先"** — 先选类型下拉再填。**修**:「+」弹出**块类型菜单**(图标+名称);纯文本块即时插入。
7. **排序只有上下箭头**。**修**:左栏**拖拽手柄**拖动排序(箭头保留为可达性回退)。
8. **删除用原生 confirm 且不可撤销**。**修**:改为非阻塞 toast「已删除 · 撤销」。
9. **几乎没有键盘支持**。**修**:Esc 关菜单/表单、Ctrl+S 保存等。
10. **悬停工具条小且隐藏**(26px)。**修**:更大点击区(≥32px)、tooltip、移到栏槽/浮层。

### MEDIUM
11. **编辑/预览模式不清晰**(在学员页内编辑)。**修**:明确「编辑模式 / 学员预览」状态条 + 视觉边框。
12. **题目块与题库脱节**。**修**:插入题目块时给选择;块内显示题目数。
13. **表单校验晚且笼统**。**修**:即时校验,未达标禁用保存,字段级提示。
14. **媒体插入分裂**(顶栏上传 vs 块内 URL)。**修**:把上传放进图片/视频块的创建里。

### LOW
15. 缺少**就地编辑占位**(纯文本仍走表单)。
16. **仪表盘缺就绪信息**(块数/题数/状态)。

## 本次修复范围(优先 CRITICAL + HIGH)
空状态、常驻「+」与块类型菜单、左栏槽控件(修遮挡)、拖拽排序、自动保存 + 状态、AI 日志折叠、模式状态条、删除 toast+撤销、仪表盘块/题计数。
